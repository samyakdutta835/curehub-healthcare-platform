# 🏥 CureHub – Smart Hospital Website

CureHub is a modern and responsive hospital website designed to provide a seamless healthcare experience for patients. It offers an intuitive interface for exploring medical services, finding doctors, booking appointments, and accessing important healthcare information.

## ✨ Features

- 🩺 Modern and attractive user interface
- 📱 Fully responsive design
- 👨‍⚕️ Doctor showcase section
- 📅 Appointment booking interface
- 🏥 Medical services and departments section
- 💬 Patient testimonials section
- 📞 Contact and emergency information
- ⚡ Smooth animations and interactive elements
- 🌙 Clean and professional design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
