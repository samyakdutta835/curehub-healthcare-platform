## 📖 About

**CureHub** is a modern and fully responsive hospital website designed to provide a seamless healthcare experience. It offers a clean interface for exploring medical services, finding doctors, booking appointments, and accessing healthcare information.

---

## ✨ Features

- 🎨 Modern and attractive UI
- 📱 Fully responsive design
- 👨‍⚕️ Doctor showcase section
- 📅 Appointment booking interface
- 🏥 Medical services and specialties
- ⭐ Patient testimonials
- 📞 Contact and emergency information
- ⚡ Smooth animations and interactions
- 🌐 Cross-browser compatibility
- 🖥️ Optimized for Desktop, Tablet, and Mobile devices

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Hospital-Website.git
```

### Navigate to the Project

```bash
cd Hospital-Website
```

### Run the Website

Simply open:

```text
index.html
```

in your browser.
